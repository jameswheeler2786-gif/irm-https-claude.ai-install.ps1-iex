FAQ

Common Questions

What is Outly?

Outly is an event-first social platform that connects people through curated, host-led experiences. Outly operates as a two-sided marketplace, where independent hosts run events and sell tickets, and users connect with fellow attendees and create meaningful connections through real-life experiences.

Who is Outly for?

Outly is purpose-built for individuals, businesses and entities interested in hosting events. They can be existing event organizers, venues, influencers, matchmakers, sports centers and any communities that bring people together in real life. Outly provides hosts with the infrastructure to build repeatable, compounding revenue.

Is Outly only for dating events?

No! Outly is for any social mixers, community gatherings and dating events – events where connection is the point. Our optional personality test powered by SoSyncd shows ticket holders compatible attendees in Pulse, which is already filtered for users' relationship preferences – dating and friends.

What is Pulse?

Pulse is Outly's user connection framework that shows ticket holders other attendees who will be attending the events to which they bought tickets. Users can nudge other users, where if the recipient nudges back, a chat between the two users unlocks.

What's in it for matchmakers?

Matchmakers often have large books of contacts who are not paying subscribers. Outly provides matchmakers with the infrastructure to run paid events for their entire network — creating a new revenue stream with no additional tech build required.

What is personality-type matching?

Personality-type matching uses psychological insights to connect users with compatible matches. It works by pairing people with enough similarities to be on the same wavelength and enough differences to create a spark.

What is SoSyncd?

So Syncd is a relationship coaching company that helps people build healthier, more secure relationships with themselves and others. It has helped over 5,000 people find compatible partners through personality-type matching.
